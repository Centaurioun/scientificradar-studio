## Doğrulanmayan ve bilerek sınıflandırılmayan

- **Scientific content responsive table (SRS-UX-10):** bu oturumdaki 4×4 blank-cell QA tablosu 320px'lik actual browser'da içerik doluluğu ile sınanmadı. Table caption save/persistence geçti. Dar ekran tablosunun kullanılabilirliği **not reproduced / evidence insufficient**, confirmed defect değil.
- **Slug/canonical route**: automatic slug loses superscript digits confirmed, but resulting route 404/collision/indexing defect not tested.
- **Existing article preservation**: no existing record edited; restore/delete/archive unsafely avoided. QA data left in local IndexedDB.
- **Unit/typecheck/lint/build/E2E**: PR body records completed prior exact-source checks; this live Brave turn did not rerun them. Playwright output is not substituted for visible interaction findings.
- **External providers**: deliberately unconfigured prototype. No real credentials/account or network calls. Provider absence is prototype scope, not an integration security breach.

## Implementation order

1. Fix reader layout within its embedded viewport (SRS-UX-01) and dashboard 320 overflow (SRS-UX-02); add responsive browser measurements.
2. Make rights evidence resolvable with secure approval/audit path (SRS-UX-04); preserve fail-closed publish policy.
3. Rework article list at desktop/tablet/mobile widths (SRS-UX-03) and test real records/source label semantics.
4. Correct draft date wording and chemistry-aware slug, then improve title/summary semantics (SRS-UX-11/06).
5. Improve Media Library caption entry and accurately label prototype Test Connection (SRS-UX-07/09).
